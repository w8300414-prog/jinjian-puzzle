# 晋见 · 古建拼图

拼起一方古建，读懂千年山西。一个无需下载、打开即玩的古建主题拼图小游戏。

## 试玩

直接打开 `index.html`，或访问线上地址：

https://w8300414-prog.github.io/jinjian-puzzle/

## 玩法

- 点击（或键盘方向键 + 回车）交换两块碎片，拼出完整画面
- 三种难度：入门 9 片 / 进阶 16 片 / 专家 25 片
- 四处文化地标：应县木塔、古建营造、陶寺观象、佛光寺东大殿
- 拼完答题，集齐「寻访藏章」

## 技术说明

- 单文件 HTML，零外部依赖（无需联网加载任何 CDN/字体），适合国内访问
- 画面为原创风格化 SVG 插画，非建筑测绘复原图
- 进度、藏章、最佳成绩均保存在浏览器本地（localStorage）
